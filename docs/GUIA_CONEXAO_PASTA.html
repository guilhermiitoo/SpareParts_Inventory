Conexão de pasta em 1 clique

Guia de engenharia para aplicar em qualquer sistema HTML da MMT que guarda dados numa pasta de rede. Referência: Spare Parts v17.54 · Guilherme Fernandes.

Como usar este guia com a IA: abra uma conversa nova, anexe o HTML do sistema e este arquivo, e cole o prompt pronto do fim da página. A IA tem tudo o que precisa aqui.

1. O que o usuário vê

Abre o sistema→ Clica em “Conectar Sistema”→ Autoriza no navegador→ ✔ Conectado, faz login
  • Um botão só na tela de login: Conectar Sistema. Não tem campo com o endereço, botão de copiar nem botão “selecionar”.
  • O endereço da pasta é fixo e fica só dentro do código.
  • Depois de conectado, aparece um cartão verde com o que foi lido (ex.: “1834 posições e 42 usuários lidos”) e o login é liberado.
  • Se o usuário marcar “Permitir em todas as visitas” na janela do navegador, nas próximas vezes o sistema conecta sozinho, sem clique.

2. As regras do navegador (o que é possível e o que não é)

❌ O navegador NÃO abre uma pasta pelo endereço. Não dá para escrever S:\MMT\... no código e abrir direto. Por segurança, o Chrome e o Edge só deixam a página usar uma pasta que o usuário escolheu numa janela, pelo menos uma vez.
✅ Mas o navegador LEMBRA a pasta escolhida. A “alça” da pasta (FileSystemDirectoryHandle) é guardada no IndexedDB. Da próxima vez, o sistema já sabe qual é a pasta e só precisa pedir a permissão, o que custa um clique e nenhuma janela de escolher pasta.
SituaçãoO que acontece ao clicar em “Conectar Sistema”
Primeira vez neste PC/navegadorAbre a janela de pasta uma única vez. O endereço já vai para o Ctrl+V sem aparecer na tela: é só colar na barra da janela e dar Enter.
Já conectou antesSó aparece o aviso do navegador “Permitir acesso?”. Nenhuma janela de pasta.
Usuário marcou “Permitir em todas as visitas”Conecta sozinho ao abrir a página, sem nenhum clique.
Escolheu a pasta erradaÉ recusada sem criar nada (arquivo de confirmação, ver item 4) e a janela abre de novo.

Outras regras importantes:

  • Pedir permissão (requestPermission) e abrir a janela (showDirectoryPicker) só funcionam dentro de um clique. Ao abrir a página, o sistema só pode consultar (queryPermission) e, se já estiver liberado, conectar sem clique.
  • Só Chrome ou Edge: o Firefox não tem essa API.
  • A memória é por PC e por navegador. Num PC novo, a primeira vez abre a janela de novo.
  • Uma permissão da pasta raiz cobre todas as subpastas (dados/, backups/...). Não precisa autorizar cada arquivo.
  • O HTML precisa ser aberto sempre do mesmo lugar. A memória é ligada à origem da página; abrir uma cópia de outro caminho começa do zero.

3. O fluxo por dentro

AO ABRIR A PÁGINA (sem clique)
  alça = IndexedDB.get('pasta')
  se existe alça E queryPermission == 'granted'  →  conectar(alça)   ← zero clique
  senão                                          →  só mostra o botão "Conectar Sistema"

AO CLICAR EM "CONECTAR SISTEMA"
  alça = IndexedDB.get('pasta')
  se existe alça:
      requestPermission('readwrite')              ← 1 clique, sem janela de pasta
      se 'granted' → conectar(alça) e FIM
      se a pasta sumiu/mudou → esquecer a alça e seguir abaixo
  copiar o endereço fixo para o Ctrl+V (silencioso)
  alça = showDirectoryPicker({ id:'meu-sistema', mode:'read' })
  conferir arquivo de confirmação; se errado → avisar e abrir de novo
  requestPermission('readwrite') → conectar(alça) → IndexedDB.put('pasta', alça)

conectar(alça)
  lê o banco → mostra cartão verde com o resumo → libera o login

4. Trava contra pasta errada

O navegador não informa o caminho completo da pasta escolhida, só o nome. Para garantir que é a pasta certa:

  • Coloque à mão, uma única vez, um arquivo de confirmação na raiz da pasta oficial. Exemplo: MEU_SISTEMA_PASTA_DO_SISTEMA.json com {"sistema":"MEU_SISTEMA_MMT"}.
  • O sistema nunca cria esse arquivo, senão qualquer pasta viraria “oficial”.
  • Abra a janela com mode:'read' e confira o arquivo antes de pedir gravação. Assim o usuário não autoriza “editar” uma pasta errada.
  • Avise o erro mais comum: quem entra na subpasta dados em vez de escolher a pasta de cima.

5. Código de referência (copiar e adaptar)

Módulo independente. Troque só o bloco CONFIG e a função aoConectar.

/* ===== ConexaoPasta: conecta a pasta do sistema em 1 clique ===== */
const ConexaoPasta = {
  CONFIG: {
    caminho:     'S:\\MMT\\...\\NOME_DA_PASTA',           // endereço fixo (só vai para o Ctrl+V)
    confirmacao: 'MEU_SISTEMA_PASTA_DO_SISTEMA.json',      // arquivo colocado à mão na pasta
    sistema:     'MEU_SISTEMA_MMT',                        // valor do campo "sistema" desse arquivo
    idJanela:    'meu-sistema',                            // o Windows lembra a última pasta aberta com este id
    idb:         'meu_sistema_handles',                    // nome do IndexedDB (único por sistema!)
  },
  dir: null,

  // ---------- memória da pasta (IndexedDB) ----------
  _db() { return new Promise((ok, err) => { const r = indexedDB.open(this.CONFIG.idb, 1);
    r.onupgradeneeded = () => r.result.createObjectStore('h'); r.onsuccess = () => ok(r.result); r.onerror = () => err(r.error); }); },
  async _get() { try { const db = await this._db(); return await new Promise(ok => {
    const q = db.transaction('h').objectStore('h').get('pasta'); q.onsuccess = () => ok(q.result || null); q.onerror = () => ok(null); }); } catch (e) { return null; } },
  async _put(v) { try { const db = await this._db(); const t = db.transaction('h', 'readwrite');
    v ? t.objectStore('h').put(v, 'pasta') : t.objectStore('h').delete('pasta'); } catch (e) {} },

  async _ehOficial(dh) {
    try { const t = await (await (await dh.getFileHandle(this.CONFIG.confirmacao)).getFile()).text();
          return JSON.parse(t).sistema === this.CONFIG.sistema; } catch (e) { return false; }
  },

  // ---------- 1) ao abrir a página: conecta sozinho se já estiver liberado ----------
  async aoAbrir() {
    if (!window.showDirectoryPicker) return;
    const dh = await this._get(); if (!dh) return;
    try { if ((await dh.queryPermission({ mode: 'readwrite' })) === 'granted') await this._conectar(dh); } catch (e) {}
  },

  // ---------- 2) o ÚNICO botão: "Conectar Sistema" ----------
  async botao() {
    if (this.dir) return;
    if (!window.showDirectoryPicker) { alert('Use Google Chrome ou Microsoft Edge.'); return; }
    const lembrada = await this._get();
    if (lembrada) {
      try {
        if ((await lembrada.requestPermission({ mode: 'readwrite' })) !== 'granted') return;  // negou: fica no botão
        if (await this._ehOficial(lembrada)) { await this._conectar(lembrada); return; }
      } catch (e) { /* pasta movida/renomeada/rede fora */ }
      await this._put(null);   // esquece e cai na escolha abaixo
    }
    try { await navigator.clipboard.writeText(this.CONFIG.caminho); } catch (e) {}   // pronto para Ctrl+V
    while (true) {
      let dh;
      try { dh = await window.showDirectoryPicker({ id: this.CONFIG.idJanela, mode: 'read' }); }
      catch (e) { if (e.name !== 'AbortError') this.erro('Não abriu a janela: ' + e.message + '. Clique de novo.'); return; }
      if (await this._ehOficial(dh)) {
        if ((await dh.requestPermission({ mode: 'readwrite' })) !== 'granted') { this.erro('Permissão de gravação negada.'); return; }
        await this._conectar(dh); return;
      }
      if (!confirm('A pasta "' + dh.name + '" NÃO é a pasta do sistema.' + (dh.name.toLowerCase() === 'dados' ? '\nNão entre em "dados": escolha a pasta de CIMA.' : '') +
                   '\n\nEscolha:\n' + this.CONFIG.caminho + '\n\nNada foi alterado. Tentar de novo?')) return;
    }
  },

  async _conectar(dh) {
    this.dir = dh;
    await this._put(dh);
    try { await this.aoConectar(dh); }
    catch (e) { this.dir = null; this.erro('Erro ao ler o banco: ' + e.message); }
  },

  // ---------- adapte ao sistema ----------
  async aoConectar(dh) {
    // 1) ler o banco da pasta (ex.: dados/banco/...)
    // 2) mostrar o cartão verde com o resumo e liberar o login:
    // document.getElementById('statusPasta').innerHTML = '✔ Conectado: ' + dh.name + '
X itens lidos.';
    // liberarLogin();
  },
  erro(msg) { const el = document.getElementById('erroPasta'); if (el) el.textContent = msg; else alert(msg); },
};
ConexaoPasta.aoAbrir();

6. O que remover dos sistemas antigos

RemoverPor quê
Campo de texto mostrando o endereço da pastaO endereço é fixo e fica no código. O usuário não precisa ver.
Botão “copiar endereço”A cópia para o Ctrl+V acontece sozinha, dentro do botão Conectar.
Botões separados “Selecionar pasta” e “Reconectar”Viraram um botão só: ele decide sozinho se abre a janela ou só pede permissão.
Pedir para escolher arquivo JSON um por umA permissão da pasta cobre todos os arquivos dela.

Mantenha o estilo de cada sistema: o botão usa as mesmas classes e cores dos botões que já existem naquela tela de login. A troca é só de comportamento, não de visual.

7. Erros comuns (já vistos na prática)

  • Pedir permissão ao abrir a página não funciona: precisa de clique. Ao abrir, só use queryPermission.
  • Muita espera antes de abrir a janela. Se o clique faz leituras lentas na rede antes do showDirectoryPicker, o navegador pode recusar (“precisa de gesto do usuário”). Abra a janela cedo; se falhar, peça para clicar de novo.
  • Mesmo nome de IndexedDB em dois sistemas faz um sistema pegar a pasta do outro. Use um nome único por sistema.
  • Esquecer a alça quando o usuário só negou a permissão. Negar não significa pasta errada: mantenha a alça e deixe o botão.
  • Criar o arquivo de confirmação pelo sistema. Nunca: ele é colocado à mão.

8. Checklist de teste

  1. PC que nunca abriu: clicar em Conectar abre a janela → Ctrl+V cola o endereço → conecta → cartão verde.
  2. Fechar e abrir de novo: clicar em Conectar não abre janela, só pede permissão.
  3. Marcar “Permitir em todas as visitas” e reabrir: conecta sozinho.
  4. Escolher a pasta dados ou outra qualquer: é recusada e nada é criado.
  5. Negar a permissão: continua no botão e funciona no próximo clique.
  6. Renomear/mover a pasta: o sistema esquece e abre a janela de novo.
